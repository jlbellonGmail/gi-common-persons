# Instalación e integración vigente

La dependencia declarada requiere Core `0.3.0` y Tenants `0.1.1`. La instalación
desde el índice público está bloqueada porque ambos paquetes no están
disponibles allí; la evidencia reproducible usa los tags locales exactos y no
equivale a una publicación.

El host entrega un `RequestContext` confiable. Persons nunca acepta actor o
tenant desde el body y no comparte registros entre organizaciones.

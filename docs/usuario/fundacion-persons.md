# Fundación de Personas

Persons es una capacidad común en diseño. Todavía no hay aplicación, endpoint
ni comandos de uso para crear personas.

La primera etapa administra registros separados por organización. Una persona
puede tener varios roles en módulos consumidores sin duplicar sus datos dentro
de la organización. Tener Person no implica una cuenta de acceso.

Consultar README y STATUS para distinguir diseño, implementación y evidencia.
No cargar datos reales ni usar la documentación como API disponible.
